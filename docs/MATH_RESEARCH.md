## Proposed research question

**How much apparent agent ability comes from an advantageous route or a permissive environment?**

Search phrase: `graph paths routing optimization constraints`

From a checkout of `topherchris420/lop-nur-twin`:

```sh
npm run rain:math:verify
npm run rain:math:portfolio -- --project satellite-vision-scape --json
```

The output ranks lexical candidates. A match is **not** a theorem-to-application mapping; the matching phrases may be unrelated to the mechanism here. The tool does not compile Lean.

## Bridge assumptions to check

1. A human, scripted policy and model operate through the same legal controls and environmental rules.
2. Paired trials share declared seeds and map versions.
3. A replayed game trace is not evidence of real-world competence.

## Next falsifiable experiment

Preregister a geometry ablation that removes one route shortcut, run human-equivalent scripted and model policies on paired seeds, and report success, collisions, and timeouts.

**Negative control:** Place a scripted stationary baseline in a level variant where the original visibility exploit no longer protects it. Check whether its success collapses even though the agent did not change.

**Deliverable:** Game-version hashes, route variants, seeds, provider identities, trajectories, negative outcomes and a signed comparison report.

## Current scientific boundary

An openai/math graph theorem can suggest a control or routing question; a lexical match never proves Jev learned a spatial strategy. A small number of recorded sessions does not estimate broad success.

This document changes no controller or game logic and establishes no experimental result. Before implementation, review source assumptions, define acceptance/failure thresholds, then run the comparator with a fixed protocol and keep failures. A formalized mathematical statement may support a **narrow mathematical lemma**, never an unrelated physical, model-skill or human claim.
