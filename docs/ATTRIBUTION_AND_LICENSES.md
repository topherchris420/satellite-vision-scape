# Attribution and licenses

Re:Earth Terrain software is MIT licensed; its DEM, geoid, imagery, and map sources retain independent licenses and attribution obligations. GeoTwn adapts architectural concepts and an HTTP boundary, not vendored source. God's Eye View is MIT licensed, while its bundled models and third-party datasets may have separate terms; GeoTwn vendors none of them.

USGS earthquake information is U.S. public-domain data and attribution is requested. Runtime users should review current USGS API policy. Any future OSM data must display OpenStreetMap contributors and ODbL attribution; Protomaps use must follow its source-data and software terms. No OSM/Protomaps data is currently bundled.

An operator must populate each production terrain manifest with the actual DEM/geoid source, version, license, and attribution before distribution. The development fixture is project-authored and illustrative.
