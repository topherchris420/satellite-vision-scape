# Structure textures — credits

All textures are CC0 (public domain) from Poly Haven, downscaled to 1k and
re-encoded as WebP. `_diff` = albedo, `_nor_gl` = OpenGL normal map,
`_arm` = ambient occlusion / roughness / metalness packed in R/G/B,
`_detail` = a single-channel mask derived from the source maps.

sheet 2 m, concrete 2.5 m, gravel 2.25 m, shutter 2 m.
